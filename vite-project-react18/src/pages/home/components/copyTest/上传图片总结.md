# 上传图片总结

## Validate

- 上传 N 张只是提供候选；每个选中组/行最终只保留 1 张 winner。
- 每次 Validate 都是**覆盖**，不是追加；未选中组/行保持不变。
- Validate 成功后上传列表清空，下一轮只使用新上传的图片。

`W1/W2` 表示两轮新选中的图片。

| Test 双列 | 类型 | 第一次 Validate | 第二次 Validate |
| --- | --- | --- | --- |
| 无数据 | 固定 Group | Evidence 按组合并并显示 `W1` | `W2` 覆盖 `W1` |
| 无数据 | 无 Group | 每行显示自己的 `W1` | 每行的 `W2` 覆盖 `W1` |
| 已有数据 | 固定 Group | `W1` 覆盖历史图片 | `W2` 覆盖 `W1` |
| 已有数据 | 无 Group | 选中行由 `W1` 覆盖 | 选中行由 `W2` 覆盖 |

## Group 与删除

- 只有存在“**非空块 / 空行 / 非空块**”时，复选框才显示 `Group`；每个连续非空块依次为 `Group 1、2...`。
- 固定 Group 的 Test Evidence 始终保持合并；删掉图片后仍保留合并单元格。
- 其他情况不显示 `Group`，复选框按来源行独立选择；回传并重新导入后也不恢复动态联动。
- 相邻行因同一 winner 临时合并时，重新 Validate 其中一行会重算该动态组；删图后会按来源 `rowspan` 拆分。
- 同组行共用 Evidence 图片，但各行仍分别保留 Passed/Failed 结果。
