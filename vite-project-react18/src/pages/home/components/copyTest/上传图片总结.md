# 上传图片与 Validate 总结

## 核心规则

- 上传 N 张图片只是提供候选。每次 Validate 会为每个选中的 Group 或独立行选择 1 张。
- Validate 是**覆盖**，不是追加。本次选中的 Test Result 和 Test Evidence 会替换为新结果，未选中的保持不变。
- Validate 成功后会清空上传列表；下一轮只使用新上传的图片。

## 两轮上传的结果

| 初始状态 | 结构 | 第一次上传并 Validate | 第二次上传并 Validate |
| --- | --- | --- | --- |
| 无历史数据 | 有 Group | 生成 Result；Evidence 按 Group 合并，显示本轮选中的 1 张图片 | 新图片和新 Result 覆盖第一轮 |
| 无历史数据 | 无 Group | 各选中行生成独立 Result 和 Evidence | 各选中行的新结果覆盖第一轮 |
| 已有历史数据 | 有 Group | 选中 Group 的新图片和 Result 覆盖历史结果 | 再次覆盖上一轮结果 |
| 已有历史数据 | 无 Group | 仅覆盖选中行；其他行保持不变 | 再次仅覆盖选中行 |

## Group 和删除图片

- 只有表格中存在“**非空块 / 空行 / 非空块**”时，复选框才显示 `Group`。每个连续非空块依次为 `Group 1、2...`。
- 有 Group：Test Evidence 始终按组合并；删除图片后，合并单元格仍保留。
- 无 Group：复选框按行独立选择。相邻行选中同一图片时，Evidence 可以临时合并；删除图片后会按原始行结构拆分。
- 无空行的历史动态合并不会恢复复选框联动。
- Group 内各行共用同一张 Evidence 图片，但 Passed/Failed 及问题提示仍按行判定。

## 用户提示

Validate 失败时只显示简短、自然的差异说明，例如：

- `Expected '输', but the image shows '輸'.`
- `The image is missing '/CCC'.`
- `The image has an extra '/'.`
- `Part of the image is too unclear to read.`

不显示位置前缀、内部占位符或重复序号；相同问题只展示一次。
