Current Challenges
03 / 08
Challenges

当前问题集中在三个方面

需求整理耗时

测试人员需要在工单、附件和会议记录之间反复切换。

用例质量波动

不同人员输出深度不同，边界和异常场景不够稳定。

回填动作重复

生成结果还需手工整理和同步，闭环不够顺畅。

核心结论

如果测试准备流程继续依赖人工扩张，使用者会持续感受到效率下降和操作负担上升。

建议口播节奏：问题不是做不到，而是准备流程不够高效。
Closed Loop
04 / 08
Workflow

通过四步形成完整闭环

1

输入需求

支持 JIRA 工单编号或本地需求文件。

2

提取信息

按字段提取 description 等关键内容。

3

生成用例

自动覆盖主流程、边界与异常场景。

4

同步回填

生成结果可直接回填 JIRA，形成追踪闭环。

这一页聚焦流程变化，不需要列出太多补充说明。
Capabilities
05 / 08
Capabilities

核心能力分为主链路与支撑能力

主链路能力

  • JIRA 工单精准检索与字段提取。
  • 需求驱动的测试用例智能生成。
  • 测试用例一键同步回填 JIRA。
  • JIRA 与本地文件双模式输入适配。

支撑能力

  • GRA / Confluence token 权限配置。
  • 多数据源接入与切换能力。
  • 按 source 筛选的历史记录查询。
  • 后续将继续优化全量检索体验。
建议这一页用“主链路 + 支撑能力”两个层级来讲。
