sequenceDiagram
    participant User as 用户
    participant Browser as 浏览器(前端)
    participant GW as 网关(Gateway)
    participant Redis as Redis
    participant Service as 后端微服务

    Note over Browser,GW: 1. 正常首次加载 (版本一致)
    User->>Browser: 打开页面
    Browser->>GW: GET / (请求入口 HTML)
    GW-->>Browser: index.html
    Browser->>GW: GET /api/version (获取后端版本)
    GW->>Redis: GET app:version
    Redis-->>GW: "20260430-01"
    GW-->>Browser: "20260430-01"
    Browser->>Browser: 将版本号存为 <br/> __CURRENT_VERSION__ = "20260430-01"

    Note over Browser,Service: 用户正常操作，所有业务请求均携带版本号
    loop 业务交互
        User->>Browser: 点击操作（如查询订单）
        Browser->>GW: GET /api/orders <br/> Header: X-App-Version: 20260430-01
        GW->>Redis: GET app:version (或使用本地缓存)
        Redis-->>GW: "20260430-01"
        GW->>GW: 版本一致 → 放行
        GW->>Service: 转发请求
        Service-->>GW: 业务数据
        GW-->>Browser: 正常响应
        Browser-->>User: 展示数据
    end

    Note over User,Redis: 2. 版本更新（发版）
    User-->>Redis: （管理员）触发刷新：<br/> curl -X POST /api/version/refresh
    GW->>Redis: SET app:version "20260430-02"
    Redis-->>GW: OK

    Note over Browser,Service: 3. 旧前端发起请求 → 被拦截
    User->>Browser: 再次点击操作
    Browser->>GW: GET /api/orders <br/> Header: X-App-Version: 20260430-01
    GW->>Redis: GET app:version
    Redis-->>GW: "20260430-02"
    GW->>GW: 版本不一致 (01 ≠ 02)
    GW-->>Browser: HTTP 426 Upgrade Required <br/> {"code":"VERSION_OUTDATED"}

    Note over Browser: 4. 前端拦截器捕获 426，弹窗强制刷新
    Browser->>Browser: Axios 响应拦截器检测到 426
    Browser-->>User: 弹出 Modal：“检测到新版本，请刷新页面”
    User->>Browser: 点击“立即刷新”
    Browser->>Browser: window.location.reload()

    Note over Browser,Service: 5. 刷新后重新加载，获得新版本号
    Browser->>GW: GET / (重新请求入口)
    GW-->>Browser: 最新 index.html
    Browser->>GW: GET /api/version
    GW->>Redis: GET app:version
    Redis-->>GW: "20260430-02"
    GW-->>Browser: "20260430-02"
    Browser->>Browser: __CURRENT_VERSION__ = "20260430-02"

    Note over Browser,Service: 6. 此后请求恢复正常
    User->>Browser: 继续操作
    Browser->>GW: GET /api/orders <br/> Header: X-App-Version: 20260430-02
    GW->>Redis: GET app:version
    Redis-->>GW: "20260430-02"
    GW->>GW: 版本一致 → 放行
    GW->>Service: 转发
    Service-->>GW: 业务数据
    GW-->>Browser: 正常响应
    Browser-->>User: 展示数据

const newApiVersion = response.headers['x-api-version'];
